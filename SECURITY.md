# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/Nerdy-Technician/Nerdy-Technician/security/advisories/new)

Include what you found, where (URL or file), and steps to reproduce. You'll get a response as soon as possible, and credit once a fix is out if you'd like it.

## Scope

This repository holds the source for the Nerdy Technician website (VitePress, deployed to GitHub Pages). For issues in a specific project (NerdyStore, JellyGlance, Nerdy-RMMScripts, etc.), please report them in that project's own repository.
